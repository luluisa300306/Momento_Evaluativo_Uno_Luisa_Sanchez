# Casa Nativa — Landing Page

Landing academico para simulación de casa de hospedaje rural en Pereira.

## Descripcion

la pagina presenta a Casa Nativa, sus servicios y un formulario visual para solicitar una reserva. El formulario utiliza validacion nativa de html, pero no envia datos a un servidor real o fictisio.

## Tecnologias 

-HTML5 y CSS3
-PureCSS 3.0
-Anime.js
-Google Fonts
-Imagen Unsplash

## Uso de PureCSS

Explore las cuadriculas responsivas, el menu, los botones y los formularios de PureCSS. En el proyecto utilice:

-'pure-g' y 'pure-u' para distribuir contenido y tarjetas.
-'pure-menu' y 'pure-menu-horizontal' para la navegacion.
-'pure-form' y 'pure-form-stacked' para el formulario.
-'pure-button' para los botones.

Los colores, la tipografia y espaciadosse personalizan estan definidos en 'style.css'. El boton hamburguesa se controla desde un java y se anima con Anime.js.

## Diseño responsivo

PureCSS organiza las colunas de contenido y servicios segun el tamaño de la pantalla, mientras que en movil, el menu se abre y cierra con el boton hamburguesa .

## Animaciones 

Anime.js anima el icono hamburguesa al abrir y cerrar el menu, el boton "reservar ahora"y las tarjetas de servicios interactuan de forma sutil con el usuario

## Formulario

Incluye informacion personal basica como: nombre, correo, telefono, fechas de llegada y salida, numero de huespedes y mensaje extra. Los campos son obligatorios y se validan en el navegador. Sin existencia de backend segun directrices.
